# Yasir Nintendo — رحلة نينتندو

تطبيق عربي RTL مستقل لتنظيم مكتبة Nintendo Switch / Switch 2 وكلاسيكيات NSO، يعمل كتطبيق PWA على GitHub Pages. مشروع محبّين غير تابع لشركة Nintendo.

## التشغيل على GitHub Pages

1. افتح **Settings → Pages** في هذا المستودع.
2. تحت **Build and deployment → Source** اختر **GitHub Actions**.
3. من **Actions → Test and deploy Nintendo Journey** شغّل **Run workflow** إذا لم يبدأ النشر تلقائيًا، أو أعد تشغيل المهمة الفاشلة بعد تفعيل Pages.
4. افتح العنوان الذي يعرضه تنفيذ النشر. المسار المتوقع لهذا المستودع: `https://yasseralq90coder.github.io/Yasirnintendo/`.
5. على Android اختر تثبيت التطبيق، وعلى iOS استخدم Safari → مشاركة → إضافة إلى الشاشة الرئيسية.

كل المسارات نسبية لدعم مجلد المستودع؛ لا تحتاج npm install أو مفتاح API. الـworkflow يختبر المشروع ثم ينشر ملفات التطبيق فقط، دون أدوات التطوير أو الملفات الشخصية.

## الميزات المنفذة

- واجهة عربية متجاوبة ومظهر فاتح/داكن؛ مكتبة فيزكال ورقمي وكلاهما وNSO.
- حالات: لم أبدأ، ألعب الآن، ختمت القصة، 100٪، متوقفة، أتمناها.
- بحث، تصفية، ترتيب حسب الاسم والساعات والتقدم، تقييم، ملاحظات وتاريخ تختيم.
- رصيد تاريخي منفصل عن الجلسات؛ مؤقت يستمر بالوقت المنقضي بعد إغلاق الصفحة، مع مراجعة المدة قبل الحفظ. لا يكتشف نشاط الجهاز تلقائيًا.
- دفتر جلسات قابل للتعديل والحذف؛ مخطط أسبوعي وتقويم 84 يومًا وإحصاءات الأنواع والمنصات والتختيم.
- XP مشتق من الساعات والتختيمات والأنواع؛ 16 إنجازًا شخصيًا مستوحى من Nintendo، وليست إنجازات رسمية.
- قسم مستقل لـNSO؛ 12 كلاسيكية مختارة، اشتراك أساسي / Expansion Pack، تخطيط شهري ثابت وأرشيف.
- 8 ألعاب Switch / Switch 2 مختارة بصور وروابط Nintendo الرسمية؛ لا تضاف أي منها تلقائيًا إلى ملكيتك.
- Backup / Restore بصيغة JSON مع تحقق ومعاينة ونسخة رجوع واحدة قبل الاستبدال.
- استيراد CSV أو قائمة JSON مع منع تكرار الاسم والمنصة؛ بيانات المستخدم محفوظة محليًا ولا تُرسل إلى GitHub.
- Offline app shell وmanifest وأيقونات PWA؛ الصور الخارجية تحتاج اتصالًا. لا توجد مكتبة تجريبية مزروعة أو إحصاءات مزيفة.

## حدود المزامنة — اقرأ قبل الاستخدام

**لم تُنفّذ مزامنة حساب Nintendo تلقائيًا.** لم نجد API عامة موثّقة تمنح موقعًا ثابتًا استيراد ملكية جميع الألعاب وأوقات اللعب. GitHub Pages استضافة ثابتة، ولا يملك الوصول إلى جلسة تسجيل دخول Nintendo في موقع آخر. لا تدخل كلمات المرور أو cookies أو session tokens في الموقع أو المستودع.

Nintendo Store وNintendo Switch App يعرضان نشاط اللعب؛ يستطيع المستخدم نقل الساعات مع تحديد المصدر «منقول من نينتندو». هذه ليست عملية سحب تلقائي ولا ضمان دقة 100٪. سجل النشاط ليس دليلًا على ملكية كل لعبة فيزكال غير مشغلة أو لعبة رقمية لم تُلعب.

توجد أدوات غير رسمية مثل nxapi، لكنها تعتمد على واجهات تطبيقات Nintendo وآليات خاصة. دمجها يحتاج مكوّنًا منفصلًا، مراجعة الإصدارات والمصادقة، وتجربة على الحساب والمنطقة المستهدفين. لم ننفذ مكوّنًا وهميًا أو نطلب رموز حسابك. لا يوجد اتصال مباشر بحساب المستخدم في هذه النسخة.

ساعات تطبيق NSO المجمع لا تُوزع على الألعاب الفردية؛ سجّل جلسة مستقلة لكل لعبة كلاسيكية. الكتالوج مختارات بتاريخ 2026-10-26، لا يدّعي الشمول أو التوفر في كل منطقة. فئات الألعاب تنظيم تحريري محلي. الصور من metadata Nintendo الرسمية؛ روابطها قد تتغير أو لا تعمل دون إنترنت.

## الحسابات

`totalMinutes = baseMinutes + sum(session.minutes)`

- 20 XP لكل ساعة مكتملة من الإجمالي.
- 300 XP لكل لعبة حالتها beaten أو complete.
- 200 XP إضافية لكل لعبة complete.
- 50 XP لكل نوع لعبة لعبته.
- نقاط الوصول إلى المستوى L: `150 × (L − 1) × L / 2`.
- لا تحصل على المكافأة مرة أخرى بتبديل حالة اللعبة. حذف/تصحيح البيانات يعيد حساب XP والإنجازات.
- التحديات تعتمد على جلسات الشهر وتاريخ التختيم، ولا تحتسب الرصيد التاريخي. ليس لها XP إضافي يمنح فرصة تكرار المكافأة عند إعادة التخطيط.
- إن غيرت الهدف أو الاشتراك بعد إنشاء الخطة، أعد التخطيط صراحة لتطبيق الإعدادات الجديدة.

## استيراد البيانات

لم يصل ملف مكتبة المستخدم خلال البناء؛ لم تُفترض ألعاب أو تختيمات. من الإعدادات نزّل قالب CSV أو ارفع قائمة JSON. قالب CSV بالأعمدة:

```csv
title,platform,genre,ownership,status,hours,rating,progress,completedAt,notes,sourceUrl,cover,tier
```

- `platform`: Switch 2, Switch, NES, SNES, Game Boy, Nintendo 64, Game Boy Advance, GameCube, SEGA Genesis, Virtual Boy.
- `ownership`: physical, digital, both, nso.
- `status`: backlog, playing, beaten, complete, paused, wishlist.
- `genre`: منصات، مغامرات، أكشن، تقمص أدوار، سباقات، ألغاز، محاكاة، رياضة، استراتيجية، أخرى.
- `hours`: الرصيد التاريخي؛ `rating`: عدد صحيح 0–5؛ `progress`: 0–100.
- `completedAt`: تاريخ ISO `YYYY-MM-DD` أو فارغ. لا تخمن تاريخ تختيمة قديمة.
- `tier`: owned للألعاب المملوكة أو standard / expansion لألعاب NSO.
- `sourceUrl` و`cover`: روابط HTTPS من نطاقات Nintendo الرسمية فقط.

استيراد الألعاب يضيف الألعاب فقط ويتجاوز المكررة؛ نقل النسخة الكاملة والجلسات يتم عبر Restore. لا ترفع نسخة بياناتك الشخصية إلى المستودع العام. الحد 20MB و10,000 لعبة و100,000 جلسة. التخزين localStorage محدود بسعة المتصفح (عادة بضعة MB)، وتفشل الكتابة برسالة دون تجاهلها. استخدم نسخة احتياطية خارج المتصفح باستمرار. جهاز جديد يحتاج استيراد النسخة؛ لا توجد مزامنة سحابية.

## التطوير والاختبارات

Node 22 أو أحدث:

```sh
npm test
npm run check
python -m http.server 8080
```

افتح localhost للاختبار. تثبيت PWA وService Worker يحتاج HTTPS أو localhost موثوقًا. عند تعديل app shell غيّر اسم الإصدار في `sw.js`؛ النسخة الجديدة تنتظر إغلاق النوافذ القديمة لضمان اتساق الملفات.

`tools/build_catalog.py` يجلب metadata عامة من صفحات Nintendo، ولا يتعامل مع الحسابات. يستخدم Python standard library. تحديث الصور والأسماء يتم عند تشغيل الأداة، وليس تلقائيًا أثناء استخدام التطبيق. راجع القائمة والتاريخ عند تحديثها.

التحقق المنفذ: اختبارات منطق البيانات وXP والتحديات والنسخ والاستيراد، فحص syntax، وتجربة حفظ لعبة وجلسة وخطة شهرية بالمتصفح. لم يُختبر الدخول إلى Nintendo لأنه غير منفذ، ولم يُختبر تثبيت فعلي على هاتف أو وضع الطيران على جهاز حقيقي.
