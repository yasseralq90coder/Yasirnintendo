# Yasir Nintendo — Kingdom Journey 2.0

تطبيق Android وPWA عربي لمكتبة Nintendo، وسجل اللعب الرسمي، والتختيمات والتحديات الشخصية. واجهة RTL متجاوبة مع وضع داكن وتقليل الحركة.

## تجربة الرحلة

- لوحة شخصية بتوصيات للاستمرار، العودة بعد غياب، إعادة التختيم، الألعاب غير الملعوبة وNSO.
- خطة تركيز لثلاث ألعاب ومفضلة، وفلاتر المكتبة حسب جهاز آخر لعب مع حفظ منصة إصدار اللعبة.
- مستويات مهنية مستمرة، رتب، و52 شارة شخصية من 13 مسارًا بأربع درجات. هذه ليست إنجازات رسمية داخل الألعاب.
- مهمات أسبوعية وشهرية من المكتبة، تُحفظ عند إنشائها مع أهداف ثابتة ونجوم موسمية وأرشيف. لا توجد مضاعفة مكافآت بزر إعادة التوليد.
- رحلات مستقلة لإعادة التختيم، وتأكيد قصة أو 100٪ مع خيار التراجع. Nintendo لا يكشف حالة التختيم؛ الراية تأكيد من اللاعب.
- مراجعة سنوية لكل سنوات الحساب، تقويم تفاعلي بالألعاب والدقائق، رسوم شهرية، ترتيب الألعاب وتصدير ملخص نصي.
- Nintendo Classics: وقت التطبيق المجمع من الحساب؛ تُختار كلاسيكيات من الكتالوج لرايات مستقلة دون توزيع ساعات التطبيق عليها.
- مطابقة مؤكدة للملف السابق مع عنوان حساب Nintendo، مع الاحتفاظ بالتختيمات وإعادة توجيه الخطط والمفضلة.

## دقة الوقت والجهاز

`totalPlayedMinutes` هو الإجمالي الرسمي، وتفاصيل الأيام تستخدم للتقويم والمهمات فقط. لا نجمع الإجمالي والأيام أو الجلسات اليدوية القديمة. تقرير الدقة يعرض أي فرق بين المجاميع الأصلية.

حسب تفضيل اللاعب الافتراضي، يُنسب النشاط اليومي من **2025-08-01** إلى جهاز Switch 2. التفضيل قابل للتعديل؛ لا يغيّر `HAC/BEE` أو معرف العنوان أو منصة إصدار اللعبة. منصة BEE قبل التاريخ تبقى Switch 2.

مدة رحلة التختيم هي الفرق بين عداد Nintendo عند بدايتها وعند تأكيد نهايتها؛ تمثل النشاط بين هاتين المزامنتين ولا تدّعي قياس تختيمة داخل اللعبة. إذا لم يوجد سجل Nintendo مستقل، تبقى المدة غير متاحة.

## قواعد المستوى

10 XP لكل 15 دقيقة من مجاميع الأيام، حتى ساعتين مكافأتين لكل يوم، و15 XP لكل يوم نشاط. مكافآت أول ثلاث تختيمات للعبة: 300 / 200 / 100؛ أول 100٪ يضيف 200 مرة واحدة. لا تضيع XP بسبب الراحة، ولا تضاف الشارات ونجوم المهمات إلى XP مرة ثانية. حدود المستوى تعتمد على `180 × level × (level + 1) / 2`.

## الخصوصية والحفظ

المكتبة محلية ولا تُضمّن نسخ المستخدم في المستودع أو APK. استيراد الملف السابق ينتقي Switch وSwitch 2، الأغلفة وبيانات التختيمات فقط؛ يستبعد الجلسات اليدوية ومفاتيح الخدمات. Backup/Restore يحفظ الرحلات والخطط والإعدادات. التفويض خارج النسخة الاحتياطية.

على Android يتم الربط مباشرة من الجهاز، وتُشفّر الجلسة بواسطة Android Keystore. على الويب فقط يحتاج الربط الشبكي خادمًا شخصيًا؛ GitHub Pages لا ينفذ طلبات Nintendo الخلفية. [دليل الخادم الاختياري](server/README.md).

## البناء

```sh
npm ci --ignore-scripts
npm test
npm run check
node tools/package-android.mjs
cd android
gradle testDebugUnitTest lintDebug assembleDebug
```

GitHub Actions يبني ويختبر APK على محاكي Android قبل استبدال تنزيل `android-preview`. مفتاح تطوير النسخ التجريبية محفوظ في cache لتسهيل التحديث فوق النسخ السابقة. Workflow Pages ينشر الملفات العامة فقط.

تنظيم الكود: `journey.js` للحسابات والمهمات والرحلات، `adventure-ui.js` للتفاعل، `core.js` للتحقق والتوافق، و`nintendo-sync.js` لحفظ بيانات المصدر. الاختبارات تستخدم أمثلة اصطناعية، ولا تتضمن نسخ مستخدمين.
