# Yasir Nintendo Android

تطبيق أصلي خفيف يستضيف ملفات الواجهة داخل APK عبر WebViewAssetLoader على أصل HTTPS محلي. لا يحمل JavaScript من GitHub Pages ولا يحتاج خادمًا أو Node على الجوال. التطبيق يدعم Android 8+، ويُبنى على GitHub عبر workflow **Build Android APK**.

## تنزيل وتثبيت

بعد نجاح البناء، افتح GitHub Releases → Android Preview ونزّل YasirNintendo.apk. يتوفر أيضًا كـArtifact باسم YasirNintendo-Android-APK في تنفيذ Actions. هذا إصدار تجريبي بتوقيع debug؛ ملف sha256 مرفق للتحقق من سلامة التنزيل. ليس إصدار متجر Play.

## الربط

من الإعدادات اختر ربط Nintendo، ثم أكمل تسجيل الدخول في متصفح النظام إلى Nintendo نفسها. التطبيق يسجل عنوان npf5c38e31cd085304b://auth ليستقبل callback تلقائيًا؛ يمكن أن يعرض Android اختيار التطبيق أو يختار تطبيق Nintendo الرسمي إن كان مثبتًا. تدعم الواجهة كذلك لصق عنوان Select this person يدويًا. لا ترسل الرابط في المحادثة.

PKCE state/verifier ومحاولة التفويض (10 دقائق) والرمز طويل الأجل وSnapshot تحفظ AES-GCM مع مفتاح Android Keystore غير قابل للتصدير. access_token وid_token في ذاكرة العملية فقط. واجهة JavaScript لا تملك مسارًا لقراءة الرموز؛ تحصل على حالة الحساب وبيانات اللعب. Android auto backup معطل؛ النسخ اليدوية لا تشمل الرموز. تُرفض روابط HTTP ولا تُعرض صفحات خارجية في WebView ذات الجسر الأصلي، وتحظر CSP الإطارات والكود الخارجي.

تجري الاتصالات عبر HTTPS باستخدام HttpURLConnection مع التحقق الافتراضي من الشهادات. لا توجد proxy أو خدمة f-token أو خادم خلفي. لو تعذر فك التخزين المشفر لا يستبدله التطبيق بصمت، بل يعرض خطأ.

## المزامنة والحسابات

نقل مباشر لمنطق Node إلى عميل Java: تحديث إجمالي الدقائق بالاستبدال، جلب أيام بصفحات، الاحتفاظ بآخر تاريخ ناجح عند فشل صفحة، تحذير عند قائمة فارغة غير متوقعة، وفصل titleId والمنصة. أوقات الأيام مستقلة عن الإجمالي، وNSO يبقى حاوية واحدة. لا يستنتج الملكية من نشاط الحساب.

عند عودة التطبيق يجرب التحديث إن مرّت ست ساعات. لا يدعي التحديث وهو مغلق أو خدمة دائمة بالخلفية. زر مراجعة التاريخ كاملًا يجلب كل صفحات الأيام. الربط الحقيقي يحتاج تجربة على حساب Nintendo، لأن المسار غير رسمي.

## التطوير

Java 17، Android SDK 35، Gradle 8.11.1، AGP 8.9.1. لا يلزم تنزيل Gradle Wrapper إلى المستودع؛ GitHub يثبت إصدار Gradle المحدد.

```sh
node tools/package-android.mjs
cd android
gradle testDebugUnitTest lintDebug assembleDebug
# مع محاكي أو هاتف موصول:
gradle connectedDebugAndroidTest
```

الاختبارات: منطق PWA/المزامنة في Node؛ اختبارات Java لبروتوكول callback وبيانات الدقائق؛ اختبار محاكي لفتح الواجهة المضمنة، إعدادات Android دون خانة خادم، وطلب حالة عبر الجسر الأصلي دون تسريب رموز. لا تستخدم حسابًا حيًا.

توقيع التطوير محفوظ في cache لتيسير التحديث؛ cache ليس مخزن توقيع إنتاج دائمًا. قبل توزيع إصدار نهائي يُجهّز مفتاح إصدار محفوظ كـGitHub Secrets دون نشره. لا نولّد مفتاح إصدار خاصًا ثم نرفعه للمستودع.
